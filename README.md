# Memory Lane Studio

Create a beautiful, "Pinterest-aesthetic" digital scrapbook website designed to store and display cherished memories, photos, and videos. The overall vibe should be lovable, nostalgic, and heavily feature a retro-styled design with cute heart motifs.

Visual Style & Colors: Use a soft, romantic vintage color palette featuring pastel pinks, muted creams, warm beige, and cherry red accents. Incorporate a subtle film-grain texture to the background to enhance the retro feel.

Typography: Blend a chunky, retro 70s serif font for the main headings with delicate, handwritten cursive scripts for captions and dates to give it a personal, "diary" feel.

Layout & UI: Design a masonry or scrapbook-style grid that looks like a curated Pinterest board. Elements should feel organic and slightly overlapping. Decorate the negative space with scattered, hand-drawn doodle hearts, sparkle icons, and digital washi tape holding the pictures up.

Photo & Video Integration: Display image uploads inside cute Polaroid-style frames with space for handwritten captions underneath. Video players should have a nostalgic 90s camcorder overlay or film-strip borders.

Animations (if applicable): Add soft, floating heart animations in the background, and make the photos gently tilt or scale up when hovered over. The entire webpage should feel like a cozy, creatively aesthetic time capsule of love and memories.

🎨 Extra Details to Include (If you are coding it yourself)

If you are building this from scratch using HTML/CSS or a platform like WordPress or Webflow, here are the specific design elements to look for to nail that aesthetic:

Color Palette:

Background: #FFF5F5 (Soft warm cream/blush)

Primary Accents: #FF6B81 (Watermelon/Heart Red)

Text/Typography: #4A4A4A (Soft Vintage Charcoal instead of harsh black)

Fonts: Search Google Fonts for "Playfair Display" or "Fraunces" for that retro, chunky aesthetic, and "Caveat" or "Dancing Script" for the handwritten memory captions.

Containers: Use CSS box-shadow to give your photos a paper-like drop shadow so they look like physical pictures sitting on a desk. Add a slight transform: rotate(-2deg); to make them look casually placed.
